# ☕ Starbucks Beverage Analytics | Power BI

An end-to-end **Business Intelligence and Data Analytics project** built with **Power BI, Power Query, DAX, and Excel** to analyze Starbucks beverage nutrition, product categories, caffeine levels, calories, sugar, and global store presence.

The project follows a practical analytics workflow:

**Raw Data → Data Cleaning → Data Transformation → Data Modeling → DAX → Interactive Dashboard → Business Insights**

---

## 📌 Project Overview

This project transforms raw Starbucks beverage and store-location data into an interactive Power BI analytics solution.

The dashboard provides a consolidated view of:

* Beverage portfolio composition
* Nutritional characteristics
* Calorie and sugar distribution
* Caffeine levels
* Beverage preparation types
* Protein content
* Starbucks store presence across countries

The objective is to demonstrate how raw business data can be converted into **interactive visual analysis and decision-support insights**.

---

## 🎯 Business Objectives

The analysis focuses on the following questions:

* What is the overall nutritional profile of Starbucks beverages?
* Which beverage categories have higher calorie and sugar levels?
* Which beverages contain the highest caffeine?
* How are Starbucks beverages distributed across categories?
* Which countries have the largest Starbucks store presence?
* How does nutritional content vary across beverage preparation types?
* How does protein content differ between beverages?

# 💡 Key Insights

The analysis identifies several notable patterns in the dataset:

* Different beverage categories show significant variation in average calorie levels.
* Espresso-based beverages tend to show relatively high caffeine concentrations.
* Sugar content varies considerably between beverage categories.
* Starbucks store presence is concentrated in a limited number of major markets.
* Beverage preparation type can materially change the nutritional profile of a product.
